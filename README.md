# Harbour

Harbour is an open hardware groovebox and synthesizer by Hügelton Instruments.

Rev. A is built around the M5Stamp ESP32-P4 and its ESP32-C6 wireless add-on.

Current targets:

- 16 performance keys
- 12 direct page keys
- 6 rotary encoders
- 320 × 240 display
- mono microphone input
- mono line input
- stereo audio output
- USB device and USB host
- TRS MIDI input and output
- microSD storage
- battery power

The firmware architecture is not final. It may share code with Felucca.

Harbour is in early development.
